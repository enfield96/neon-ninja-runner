# Neon Ninja Runner — Present Simple edition

Бесконечный раннер в неоновом ретро-стиле, где ускорение нужно заслужить: чтобы
взлететь над дорожками, игрок отвечает на вопрос по **Present Simple**.

Один HTML-файл. Без сборки, без библиотек, без внешних ассетов — вся графика
рисуется на canvas, музыку и звуки синтезирует Web Audio.

## Играть

Откройте `index.html` двойным кликом или по ссылке GitHub Pages.

## Управление

| Действие | Клавиши |
|---|---|
| Сменить полосу | ← → или A D |
| Прыжок | ↑ или Space |
| Подкат | ↓ или S |
| Ответ в квизе | 1, 2, 3 |
| На телефоне | свайпы |

## Как устроен геймплей

- Три полосы, растущая скорость, три типа препятствий: барьер (прыжок),
  лазерные ворота (подкат), поезд (только объехать).
- Каждые ~10 секунд появляется зелёная стрелка «B». Подобрали — открывается
  вопрос с тремя вариантами и таймером (45 с в начале, минимум 20 с).
- Верный ответ — полёт над дорожками на тройной скорости и золотые монеты в небе.
  Ошибка или истечение времени — герой просто бежит дальше.
- 150 заданий по Present Simple: утверждение, отрицание, вопрос. Подряд идёт не
  больше двух заданий одного типа.

## Что под капотом

- `Canvas 2D` и самописная перспективная проекция для псевдо-3D тоннеля.
- Следящая камера с креном, дэш-анимация с призрачным шлейфом, эффекты ускорения.
- Процедурный чиптюн-саундтрек и синтезированные звуковые эффекты (Web Audio),
  две независимые кнопки громкости — музыка и эффекты.
- Рекорд и настройки звука хранятся в `localStorage`.
